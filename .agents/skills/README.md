# Shared skills

On-demand workflows shared by coding agents live in `<name>/SKILL.md`; detailed
tool resources live in that skill's `references/` directory.

[Agent-tooling guidance](../../.github/instructions/agent-tooling.instructions.md)
owns metadata/discovery requirements. [Documentation ownership](../../.github/instructions/documentation.instructions.md)
defines the boundary between skills, policies, and reference guides.
