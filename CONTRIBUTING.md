# Contributing

Contributions are welcome. Start with the shared
[development instructions](.github/instructions/README.md):

- [Development rules](.github/instructions/development.instructions.md) and
  [environment setup and validation](docs/DEVELOPMENT.md)
- [Test design and Home Assistant mocks](.github/instructions/testing.instructions.md)
- [CI rules](.github/instructions/ci.instructions.md) and
  [checks and fork approvals](docs/CI.md)
- [Branches, PRs, issue references, and releases](.github/instructions/git-workflow.instructions.md)
- [Issue creation, completion, and beta feedback](.github/instructions/issues.instructions.md)
- [Documentation ownership](.github/instructions/documentation.instructions.md)

These are the authoritative instructions for contributors and coding agents.
[AGENTS.md](AGENTS.md) provides the agent guidance map; shared on-demand
workflows live in [`.agents/skills/`](.agents/skills/README.md).
Reference documentation and detailed contributor/maintainer guides live in
[`docs/`](docs/README.md).

For support requests, follow [issue reporting](docs/ISSUE_REPORTING.md).
For vulnerabilities, follow [SECURITY.md](SECURITY.md).
